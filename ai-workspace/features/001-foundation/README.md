# 001 Foundation — Colaboración con IA

## Objetivo y reparto del trabajo

Utilizar Codex para preparar una base Full-Stack ejecutable y completar los controles necesarios antes de desarrollar funcionalidades de negocio.

La dirección del proyecto fijó el stack y las exclusiones del encargo, solicitó analizar lo existente antes de modificarlo y autorizó completar los elementos pendientes. Se delegaron en Codex la comprobación de herramientas, implementación de la infraestructura, diagnóstico de discrepancias, preparación de pruebas y ejecución de controles.

Las soluciones técnicas de implementación y sus correcciones se revisan a través de la evidencia conservada; no se atribuyen al usuario decisiones técnicas o pruebas personales que no estén documentadas.

## Cómo se condujo la colaboración

El trabajo comenzó con un encargo acotado de infraestructura. La spec formal se incorporó después del esqueleto inicial: se contrastó con el repositorio para conservar lo válido y resolver los huecos de controles y contexto. Esta secuencia permitió dirigir el cierre sin repetir la inicialización ni ampliar a negocio o persistencia.

- [Prompts consolidados](prompts.md): selección de instrucciones por objetivo, basada en las fuentes disponibles.
- [Iteraciones relevantes](iterations.md): ajustes de alcance y correcciones verificables durante el desarrollo.
