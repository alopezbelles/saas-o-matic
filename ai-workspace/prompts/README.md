# Instrucciones técnicas para la IA

Se priorizan registros estructurados con contexto, objetivo, alcance, restricciones, decisiones y criterios de verificación.
Cada registro identifica su procedencia y momento de redacción:

- **Instrucción técnica previa:** preparada antes de ejecutar el bloque; indicar si se utilizó realmente para guiarlo.
- **Reformulación técnica retrospectiva:** explica solicitudes y contexto anteriores con una redacción más elaborada; no es texto original enviado.
- **Cita literal opcional:** solo cuando aporte valor, conservando el mensaje real y su atribución.
